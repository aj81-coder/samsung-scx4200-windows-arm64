Samsung SCX-4200 printing on Windows 11 ARM64 - Preview 0.12.1

The legacy Samsung SCX-4200 Windows driver does not support Windows 11 ARM64.
This app enables ordinary USB printing: install once, then select the printer
in normal applications. It runs in the background and starts at sign-in.
Basic printing has been tested; this version is now in regular household use.
Scanning has not been addressed; future investigation is being considered.
Supported output: A4, monochrome, 300 dpi, one copy, single-sided.
This personal project was developed with OpenAI ChatGPT and Codex, including
substantial AI technical decisions, code, tests and AI-generated documentation.
See AI-PROVENANCE.md and VALIDATION.md for details and evidence limits.

FIRST INSTALLATION

1. Windows 11 ARM64 is required. Turn on the SCX-4200, connect its USB cable and
   load A4 paper. Extract this ZIP into a new folder on the laptop's internal drive.
2. Double-click INSTALL.cmd as your usual Windows user and wait for Installed.
   If no supported queue exists, setup attempts to create Samsung SCX-4200.
3. Only if setup reports permission denied creating the printer: right-click
   ADD-PRINTER.cmd, choose Run as administrator, then run INSTALL.cmd again as
   your usual user. INSTALL itself is a per-user installation.
4. Print a short document and check the paper. Keep this package folder; it may
   contain the receipt needed for optional removal of the queue it created.

UPGRADING YOUR WORKING 0.12.0 INSTALLATION

1. Finish printing. If an interrupted job needs recovery, complete recovery in
   the old app first. Keep SCX-4200 Capture Test installed, with no jobs in it.
2. Click the hidden-icons arrow beside the Windows clock if needed. Right-click
   the old app icon, choose Quit and wait for the icon to disappear. The old icon
   may look generic. Stop printing alone does not quit the app.
3. Open your old SCX4200-General-Preview-0.12.0-arm64 folder and double-click
   UNINSTALL.cmd. This preserves your printer queue and diagnostic data.
   If it says the app is still running, check step 2. If it refuses for another
   reason, keep the message; do not delete the installation manually.
4. Extract this new ZIP into a new folder on the laptop's internal drive.
   Keep the extracted folder. Double-click INSTALL.cmd as your usual user.
5. Wait for Installed. Find the new printer-shaped icon beside the clock.
   Your existing printer remains named SCX-4200 Capture Test; this is expected.
6. Use it normally. You do not need to repeat a physical print test series for
   the housekeeping/icon update. Report a problem if one appears in ordinary use.

If upgrading directly from 0.11.1, use UNINSTALL.cmd in that older package at
step 3. If your existing queue is Samsung SCX-4200, keep that queue instead.
Never run an old bridge alongside the installed background app.

EVERYDAY PRINTING

Turn on the printer, connect USB and load paper. Choose Print in your normal
application, select Samsung SCX-4200 (or retained SCX-4200 Capture Test), A4,
one copy, single-sided. Click Print once. The app starts when you sign in.
If you deliberately quit it, open Samsung SCX-4200 from the Start menu.
No console, old bridge command or second computer is needed.

If paper runs out, refill it and let the existing job continue. Do not print
again. If the app reports an uncertain/stopped job, follow the recovery steps
in USER-GUIDE.txt. Cancellation cannot erase printer-buffered data.
Keep the laptop awake while printing.

STORAGE AND HOUSEKEEPING

Successful temporary print data is normally cleared automatically. Before each
engine start, housekeeping keeps ten recent eligible clean sessions across
restarts and prunes older sessions only after checking their successful state
and known file layout. This is a history limit, not a page-count limit.
Successful Cancel/Diagnostics reports keep a combined recent history of twenty.

Failed, interrupted, unknown or linked content is preserved. All recovery
reports, recovery backups and manually saved diagnostic ZIPs are preserved.
These can still grow storage; there is no unconditional total-size cap.
No regular manual cleanup is needed for successful printing. You may remove
a saved diagnostic ZIP you created when you no longer need it. Do not remove
session folders, lock files or recovery backups to force a restart.
