FOREGROUND PREVIEW SOURCE BUILD - AUDITED RECIPE

Runtime commands use Windows PowerShell5.1. DEVELOPMENT BUILDS require
PowerShell7: the patch generators depend on its string-overload behavior.
The audit host is Windows x64. No Python or PowerShell7 is required simply
to use the printer package on the target ARM64 laptop.

Extract source.zip into a fresh folder. Top directory source-package-0.8.0
is a historical name; its current renderer is0.9.2. Old component READMEs
describe earlier experiments. Use this top-level recipe for the current build.

Install the official Zig0.15.2 Windows x64 distribution under
 .tools/zig-x86_64-windows-0.15.2
Its ZIP SHA256 is
 3a0ed1e8799a2f8ce2a6e6290a9ff22e6906f8227865911fb7ddedc3cc14cb0c
The compiler is a separate development prerequisite; do not trust a package
just because it is called Zig. Verify the archive against this pin.

Open PowerShell7 and run from the extracted source folder:
 ./native-preview/rebuild-from-source.ps1 -Architecture both

The script checks all source archive pins, extracts CUPS/PAPPL/zlib/SpliX,
builds both architectures and assembles build/async/ARCH. It never prints or
changes Windows queues. It records output hashes in build/rebuild-TIME.json.
For a deliberate repeat build, -UseExistingSources preserves the existing
upstream directories and cache; use a fresh tree for a clean-source audit.

Individual commands, in order:
 native-async-bridge/build-dependencies.ps1 -Architecture ARCH
 native-render-print/build-renderer.ps1 -Architecture ARCH -OutputRoot build/margin-fix
 native-reliable-bridge/sender-build.ps1
 native-async-bridge/build-bridge.ps1 -Architecture ARCH -RendererRoot build/margin-fix

The explicit RendererRoot is required with that output layout. The older
0.10.0recipe omitted it and could copy a stale converter in an existing tree.
It failed to assemble from a clean tree. No C/C++ code change was needed.

SpliX extracts to splix-7a802180c7b50802aaa16bbd2b3e326237286730 beside its ZIP.

For tests, Python with Pillow/NumPy is a development prerequisite. The
synthetic margin suite is native-render-print/test-margin-fit.py OUTDIR.
Also build native-render-print/sender-build.ps1 for its offline single-page
validator. Optional original-renderer/private-target comparisons explicitly
report SKIP when historical artifacts are unavailable. The synthetic checks
do not need private documents. Never automate production real-USB printing.

Source-build success and byte-for-byte binary reproducibility are separate
claims. Read the audit record for measured results, differing build paths,
recipe corrections, runtime tests, and remaining release gates.
